# Chess clock

A simple chess clock built with React and TypeScript.

## Features
- two-player chess clock
- configurable time controls with optional Fischer increment
- pause and resume buttons
- timeout handling
- low-time precision
- keyboard controls

## Controls
- `A` - white finishes their move
- `L` - black finishes their move
- `Space` - pause/resume

## Tech stack
- React
- TypeScript
- Vite
